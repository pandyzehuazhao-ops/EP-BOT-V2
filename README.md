# EP-BOT-V2
A script that does Education perfect Language tasks (Reading, Writing, Listening, Speaking, Dictation).

# How to use
In the Education Perfect website, right click and select 'Inspect'. In the developer's menu, paste the contents of script.js into the console and press enter (you may need to allow pasting).

Now if you are on a question, clicking the backslash key will automatically answer the questions.
